# Learn — shared workflow

Capture the requested topic, or meaningful learning from the current conversation.
Read BRAIN.md for frontmatter, wikilinks and note formats. Classify the result:

- Durable project decision → `projects/<slug>/decisions/` with rationale and hub link.
- Recipe reusable across projects → `patterns/<topic>.md`, linked to its origin.
- Personal concept → `learning/<topic>/<slug>.md` (durable, one idea).
- Resource → the same topic directory, with in-progress/done/dropped status.
- TIL → `learning/til/YYYY-MM-DD-slug.md` (a small fact worth retaining).

Search the relevant topic in learning, patterns, decisions and indexes before
creating a note; update an existing concept instead of duplicating it. Write
atomic notes in your own words with ISO date and contextual links. On the third
related note, create a topic MOC if missing and link it from home. Promote a
proven TIL to concept while preserving its original link. Report paths and links.

Do not update live CONTEXT merely to capture study. Project state changes use
close. Never store secret values or make up knowledge not established in the work.
